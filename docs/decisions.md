## Implementation decisions (Phase 0, Sept 21, 2026)

| Decision          | Choice and why                                                                                                                                                                                                                                                                                                                                                             |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local database    | `npm run db:local` serves an embedded PGlite Postgres over the wire protocol on 127.0.0.1:5433. Next 16's dev server renders in several worker processes, which corrupts a file-backed PGlite opened directly; a socket server gives every process one shared database. Tests use in-memory PGlite with the real migrations, so no service is needed in CI.               |
| Driver selection  | `DATABASE_URL` decides: a `neon.tech` host uses `@neondatabase/serverless` over HTTP; anything else uses `pg`. Same Drizzle schema either way.                                                                                                                                                                                                                              |
| Package type      | ESM (`"type": "module"`) so `tsx` scripts can import the database client.                                                                                                                                                                                                                                                                                                  |
| Authorization     | Guards in `src/lib/authz.ts` throw a typed `AuthzError` (401/403/404); `withAuthz` and `withAuthzRoute` convert it. Missing resources are 404, someone else's are 403. The ESLint rule `bloom/require-authz` requires a guard in every `"use server"` export and API route method; `publicRoute` / `publicAction` mark the few intentionally open ones (health, login, signup, logout). |
| Route protection  | `src/proxy.ts` (Next 16's replacement for middleware) using the proxy-safe Auth.js config. JWT sessions carry `userId` and `role`, 12-hour max age, no database hit per request.                                                                                                                                                                                             |
| Passwords         | bcryptjs, 10 rounds. Student temp passwords are readable words (`maple-7482`), shown to the teacher once, never stored in plain text; `must_change_password` stays set until the student changes it (Phase 1 UI).                                                                                                                                                              |
| shadcn            | v4 (Base UI). The old `form` component no longer exists; `field` is its successor. `toast` is Base UI's toast.                                                                                                                                                                                                                                                              |
| Design tokens     | PLAN.md §5 colors as CSS variables wired to shadcn's semantic tokens: `primary` = coral for buttons, `sidebar` = teal, `ring` = teal, radius 8px. Inter (body) + Lexend (headings) via `next/font`. Light-only until Phase 3.                                                                                                                                                |
| Prettier          | Excludes Markdown after it rewrote spec text (`/app/*` became `/app/_`).                                                                                                                                                                                                                                                                                                   |
| Typecheck         | `next typegen` runs before `tsc` because Next 16 generates global types such as `LayoutProps`.                                                                                                                                                                                                                                                                             |
| `updated_at`      | One trigger function applied to every table with the column (migration `0001`); re-run its DO block after adding tables.                                                                                                                                                                                                                                                   |
| Media storage     | Cloudflare R2 via the S3 SDK. Browsers PUT straight to a presigned URL (10 min, owner-namespaced UUID key), then the server verifies with HEAD and records `media_assets`. Files are served through `/api/media/<key>` to signed-in users unless `R2_PUBLIC_URL` is set. Limits: images 10 MB, video 200 MB, audio 30 MB. Tests run against an in-memory S3 stub (`src/test/s3-stub.ts`), so R2 credentials are only needed to use uploads, not to test them. |
| Shared stimuli    | A stimulus is a course-level row (text, image, video, audio) referenced by `questions.stimulus_id`. Grouping is a pure helper (`src/lib/stimulus-groups.ts`): first-appearance order, one group per stimulus, contiguous. Pools carry `draw_stimulus_groups` so a draw can pull a whole group (used by the builder in 1.7). Deleting a stimulus that live questions use is refused; detach first. |
